Ajustes y respaldo

Respaldo de datos y capturas

Se guardan localmente en este navegador (IndexedDB). No hay sincronización entre dispositivos. Si eliminas los datos del sitio, puedes perder el Journal. Haz copias de seguridad frecuentes.

El respaldo JSON incluye las capturas adjuntas y puede ocupar bastante espacio. Consérvalo en un lugar seguro: contiene información financiera personal.

Instalación y privacidad

Sube únicamente index.html a GitHub. Tus trades, cuentas y fotos se guardan en el dispositivo, no dentro del repositorio. Publicar este archivo no sincroniza datos entre iPhone y Mac; para eso necesitaríamos autenticación y un backend privado.

Nueva cuenta

Los límites se registran por cuenta. La app no puede verificar el drawdown EOD/intradía oficial sin los saldos y máximos históricos del proveedor; no uses la estimación como margen disponible garantizado.
